# KCS ダッシュボード & 勤怠システム 統合開発：引継ぎ資料

## 1. プロジェクト概要
- **目的**: 既存の勤怠管理システム（AppA, B, C）を、KCS合同会社のポータルダッシュボード（React/Vite）へ統合し、一元管理を可能にする。
- **技術スタック**:
    - **フロントエンド**: React (Vite), CSS (Vanilla), Firebase Hosting
    - **バックエンド**: Google Apps Script (GAS)
    - **連携方法**: `fetch` APIによるJSON通信

## 2. これまでに完了した作業
### フロントエンド (APP会社/)
- **アーキテクチャ刷新**: 3000行超の `App.jsx` をリファクタリングし、`src/views/` に各画面をコンポーネント化。
- **勤怠管理画面 (`AttendanceView.jsx`) の実装**:
    - 今日の稼働状況、スタッフ一覧、店舗一覧、シフト同期、QRコード生成、月次PDFレポート生成を統合。
    - エラーガード（Array.isArray）およびアンマウント時のステータス更新防止策を導入し、安定性を向上。
- **SNS運用画面 (`XView.jsx`) の実装**:
    - X (Twitter) API v2 を使用したリアルタイム投稿機能を統合。
- **設定管理 (`SettingsView.jsx`)**:
    - 複数のGAS URL（本部用と勤怠用）を個別に設定できるようラベル分けを実施。

### バックエンド (GAS)
- **勤怠バックエンド (`AppA_Backend.gs`)**:
    - AppB, AppC のロジックを AppA に集約し、ひとつのWebアプリURLで全操作（同期、PDF、QR等）を完結可能にした。
    - 外部マスターSSからの「店舗一覧」「スタッフ一覧」の同期機能 (`syncMaster`) を追加。
- **本社・SNSバックエンド (`GAS_KCS合同会社_Backend.gs`)**:
    - OAuth 1.0a 署名ロジックを手動実装し、GASから直接 X への投稿を可能にした。

## 5. 次のエージェントへの注意点
> [!IMPORTANT]
> **GASのデプロイバージョン管理**: GAS側のコードを変更した後は、必ず「新しいバージョン」としてデプロイし直さないと、ウェブアプリURLに修正が反映されません。
> 
> **Syntax Error対策**: すべての `.gs` ファイルはグローバルスコープを共有します。複数のファイルに同じ定数名（例: `CONFIG_TABLES`）があると全機能が停止するため、重複には注意してください。
