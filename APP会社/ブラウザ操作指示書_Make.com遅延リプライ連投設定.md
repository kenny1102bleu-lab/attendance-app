# 「アフィリエイト本投稿 → 遅延 → リプライ欄にリンク自動配置」フロー

---

## 📖 この手順書の目的

社長のパソコンが電源オフの状態でも、メイク（Make.com）のクラウド上で以下を完全自動化します：

1. **エックス（X）への本投稿**（画像付きアフィリエイト紹介ツイート）
2. **３秒〜５秒の遅延処理**（エックスのアルゴリズム対策）
3. **リプライ欄への商品リンク自動配置**（アフィリエイト収益化）

## 📋 メイク（Make.com）シナリオの作成手順

### ステップ 1：新しいシナリオを作成

1. メイク（Make.com）にログイン → 「Create a new scenario」をクリック
2. シナリオ名を「**KCS すなくん アフィリエイト遅延連投フロー**」に設定

---

### ステップ 2：トリガーの設定（ジーエーエスからの呼び出し）

**モジュール選択：** `HTTP - Make a request` → 「Watch incoming webhooks」

1. 「Add」ボタンでウェブフック（Webhook）を追加
2. **ウェブフック名：** `KCS_アフィリエイト投稿トリガー`
3. 生成されたウェブフックURLをコピーして、ジーエーエスの設定シートに以下のキーで保存：

```
キー名: MAKE_AFFILIATE_WEBHOOK_URL
値: （コピーしたウェブフックURL）
```

> **受け取るデータ形式（JSON）：**
> ```json
> {
>   "account": "sunakun",
>   "tweetText": "本投稿のテキスト内容",
>   "affiliateLink": "https://affiliate-link.com/xxxx",
>   "imageBase64": "（省略可：Base64エンコードされた画像データ）"
> }
> ```

---

### ステップ 3：エックス（X）への本投稿モジュール

**モジュール選択：** `HTTP - Make a request`（ツイッターは直接モジュールではなくエーピーアイ（API）を使う）

| 設定項目 | 値 |
|---------|---|
| URL | `https://api.twitter.com/2/tweets` |
| メソッド（Method） | `POST` |
| ヘッダー（Headers） | `Authorization: OAuth ...（すなくん用の署名を生成）` |
| ボディ（Body Type） | `application/json` |
| ボディの内容 | `{"text": "{{1.tweetText}}"}` |

**簡易設定：GASのエンドポイントに投稿を委託する方法（推奨）**

より簡単な方法として、ジーエーエス（GAS）にエックス投稿を委託することをお勧めします：

| 設定項目 | 値 |
|---------|---|
| URL | `（GASのウェブアプリURL）` |
| メソッド（Method） | `POST` |
| ボディ（Body Type） | `application/json` |

```json
{
  "action": "test_sunakun_post",
  "text": "{{1.tweetText}}"
}
```

**レスポンスのマッピング：**
- `data.tweetId` → 次のモジュールへ渡す投稿ID

---

### ステップ 4：🔑 最重要！「遅延処理（Delay）」モジュールの設定

> ここがメイク（Make.com）の真骨頂！エックスのアルゴリズムに「外部リンク投稿」と見なされないよう、本投稿の直後に遅延を入れます。

**モジュール選択：** `Flow Control - Sleep`

| 設定項目 | 値 |
|---------|---|
| 遅延時間（Duration） | `5`（秒） |
| 単位（Unit） | `Seconds`（秒） |

> **💡 ポイント：** この5秒の遅延が収益化の要！エックスは投稿直後のリプライを「会話の継続」として高く評価し、スパムフィルターにかかりにくくなります。

---

### ステップ 5：リプライ欄へのアフィリエイトリンク自動配置

**モジュール選択：** `HTTP - Make a request`

GASのエンドポイントを叩いて、すなくんアカウントでリプライ投稿を実行：

| 設定項目 | 値 |
|---------|---|
| URL | `（GASのウェブアプリURL）` |
| メソッド（Method） | `POST` |
| ボディ（Body Type） | `application/json` |

```json
{
  "action": "post_affiliate_reply",
  "tweetId": "{{3.data.tweetId}}",
  "replyText": "🛒 商品ページはこちら！\n\n{{1.affiliateLink}}\n\n#アフィリエイト #お得情報",
  "account": "sunakun"
}
```

---

### ステップ 6：ディスコード（Discord）への完了通知

**モジュール選択：** `HTTP - Make a request`

| 設定項目 | 値 |
|---------|---|
| URL | `（ディスコードのウェブフックURL）` |
| メソッド（Method） | `POST` |
| ボディ（Body Type） | `application/json` |

```json
{
  "content": "✅ **アフィリエイト遅延連投が完了しました！**\n\n📢 本投稿ID: `{{3.data.tweetId}}`\n🔗 アフィリエイトリンク: {{1.affiliateLink}}\n⏰ 実行日時: {{now}}",
  "username": "KCS メイク（Make）ボット"
}
```

---

### ステップ 7：スケジュール設定

シナリオのトリガーを「定期実行」に変更する場合：

**モジュール選択：** `Schedule - At regular intervals`

| 設定項目 | 推奨値 |
|---------|-------|
| 実行間隔 | `毎日` |
| 実行時刻 | `12:00, 19:00, 22:00`（1日3回） |

## 📌 GAS側に追加した新機能

ジーエーエス（GAS）のファイル `GAS_KCS合同会社_Backend.gs` に以下の新しいエンドポイントを追加済みです：

| エンドポイント（action） | 機能 |
|---------|------|
| `post_affiliate_reply` | 指定した投稿IDのリプライ欄にアフィリエイトリンクを投稿 |
| `approve_patch` | パッチID指定で自己修復コードを本番適用 |
| `check_system_emails` | システムメールのスキャンを手動実行 |

---

## ⚠️ 注意事項

1. **メイク（Make.com）の無料プランでは月1,000オペレーション** までが上限。1日3回投稿 × 3ステップ = 1日9オペレーションなので、月約270オペレーション（無料プランで十分）。
2. エックス（X）のエーピーアイには**基本プランで月に1,500ツイートの投稿制限**があります。1日3回 × 30日 = 90ツイート。余裕があります。
3. 遅延処理の時間は5秒を基本としていますが、エックスのポリシー変更に応じて調整してください。
