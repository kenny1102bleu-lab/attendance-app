## 1. GAS — コード更新 & 新バージョンデプロイ

### 1-1. ローカルのコードをコピーする

PCで以下のファイルを開いてください：

```
c:\Users\kenny\.gemini\antigravity\scratch\attendance_app\APP会社\GAS_KCS合同会社_Backend.gs
```

**VSCode または メモ帳で開いて、全選択（Ctrl+A）→ コピー（Ctrl+C）**

---

### 1-2. GAS エディターを開く

1. ブラウザで Google スプレッドシートを開く  
   （KCS合同会社のスプレッドシート）

2. メニュー → **拡張機能** → **Apps Script**  
   → 新しいタブで GAS エディターが開く

---

### 1-3. コードを貼り付ける

1. GAS エディターの左側に `コード.gs` があることを確認
2. エディター内を**全選択**（Ctrl+A）
3. コピーしたコードを**貼り付け**（Ctrl+V）
4. **保存**（Ctrl+S）

> ⚠️ 複数のファイルがある場合は `コード.gs` または `GAS_KCS合同会社_Backend.gs` に貼り付けること

---

### 1-4. 新バージョンとしてデプロイ

1. 右上の **「デプロイ」** ボタン → **「デプロイを管理」**

2. 右上の **「新しいデプロイ」** をクリック

3. 設定：
   | 項目 | 値 |
   |---|---|
   | 種類 | ウェブアプリ |
   | 説明 | ハイブリッド対応（HAL/すなくん/画像ルーティング追加） |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |

4. **「デプロイ」** をクリック

5. 権限の確認画面が出たら **「アクセスを承認」** → Googleアカウントを選択 → 「詳細」→「安全ではないページに移動」→ 「許可」

6. デプロイ完了画面の **「ウェブアプリURL」** が表示される  
   → `bridge.config.json` のURLと同じであれば変更不要（GAS URLは変わらない）

> ✅ URLは変わらないので Make.com / n8n の設定変更は不要

GAS エディターの上部メニュー → **「実行」** → 関数名 `setupKCS` を選択 → **「実行」**

## 2. Make.com — Scenario 2 作成（#knowledge 画像解析）

> Scenario 1（KCS本部チャンネル）はすでに完成済み。今回は Scenario 2 を新規作成する。

### 2-0. 事前準備：#knowledge チャンネルのIDを確認

1. **Discord** を開く
2. **#knowledge チャンネル**を右クリック
3. **「チャンネルIDをコピー」** を選択  
   ※「コピー」が見えない場合: Discord の設定 → 詳細設定 → 開発者モード を ON にしてから再試行

コピーしたID（例: `1234567890123456789`）を手元にメモしておく

---

### 2-1. 新シナリオを作成

1. ブラウザで **Make.com** にログイン
2. 左メニュー **「Scenarios」** → **「＋ Create a new scenario」**
3. シナリオ名（後で変更可）: そのまま進んでOK

---

### 2-2. Discord「Watch Messages」モジュールを追加

1. 画面中央の **「＋」** をクリック
2. 検索バーに `Discord` と入力 → **Discord** を選択
3. アクション一覧から **「Watch Messages」** を選択

4. Connection の設定：
   - 「Add」は**押さない**
   - ドロップダウンから **既存の `KCS Discord Bot`** を選択  
     ※ Scenario 1 で作成済みの接続を再利用できる

5. チャンネル設定：
   | 設定項目 | 値 |
   |---|---|
   | Channel | 手順2-0でコピーした **#knowledge のチャンネルID** |
   | Limit | `5` |

6. 「Watch from now on」を選択（過去メッセージを処理しないため）

7. **「OK」** をクリック

---

### 2-3. フィルターを追加（画像添付のみ通過）

1. Watch Messages モジュールの右側の矢印（→）をクリック
2. **「Set up a filter」** を選択
3. 以下のように設定：

   | 設定 | 値 |
   |---|---|
   | Label | `画像添付フィルター` |
   | Condition の左辺 | `{{1.attachments[]}}` |
   | Operator | **exists**（「存在する」） |

4. **「OK」** をクリック

---

### 2-4. HTTP「Make a request」モジュールを追加

1. フィルターの右側の **「＋」** をクリック
2. `HTTP` と検索 → **「Make a request」** を選択
3. 以下のように設定：

**URL**
```
https://script.google.com/macros/s/AKfycbxmVS3EyDiT8KtX4r10SIE8eDu3ri_7aRbYXR4kFpEqSKuQnDsJLlTO1HV6p7RW1mTF/exec
```

**Method**
```
POST
```

**Headers**（「Add item」をクリックして追加）
| Name | Value |
|---|---|
| `Content-Type` | `application/json` |

**Body type**
```
Raw
```

**Content type**
```
JSON (application/json)
```

**Request content**（以下をそのままコピペ）
```json
{
  "action": "discord_message",
  "channelId": "{{1.channel_id}}",
  "text": "[画像添付]",
  "author": "{{1.author.username}}",
  "imageUrl": "{{1.attachments[].url}}"
}
```

> ⚠️ `{{1.attachments[].url}}` の部分はマッピングパネルから入力すると確実  
> → 入力欄をクリック → 右上のマッピングアイコン → `1. Watch Messages` → `Attachments[]` → `URL`

**Parse response**
```
Yes（チェックを入れる）
```

4. **「OK」** をクリック

## よくあるエラー対処

| エラー | 原因 | 対処 |
|---|---|---|
| Make.com: 401エラー | Bot Token が間違っている | GAS設定シートの `DISCORD_BOT_TOKEN` を再確認 |
| Make.com: 成功するが返答なし | GASのWebhook URLが未設定 | 設定シートの `DISCORD_WEBHOOK_URLS` を確認 |
| `HAL:` コマンドで「生成失敗」 | `CLAUDE_API_KEY` 未設定 | GAS設定シートに入力（または `useGemini: true` がfallback） |
| 画像解析で「GEMINI_API_KEY未設定」 | APIキーが空 | GAS設定シートの `GEMINI_API_KEY` を入力 |
| n8n: `$env.KCS_GAS_URL` が空 | 環境変数未設定 | Settings → Variables で設定し直す |
| 返答が2回来る | GASのトリガーと二重処理 | GAS エディター → トリガー → `discordAgentTick` を削除 |
