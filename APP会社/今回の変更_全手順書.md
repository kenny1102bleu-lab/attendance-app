## 今回変えたこと（概要）

| 変更前 | 変更後 |
|---|---|
| Make.com が1分ごとにDiscordをポーリング | Discord が GAS を直接呼ぶ（ポーリングなし） |
| `!ヘルプ` `HAL: テーマ` などテキスト入力 | `/help` `/hal テーマ:推し活` スラッシュコマンド |
| n8n で朝礼・日次レポートをスケジュール | GAS 内蔵トリガーで完結 |

| ナレッジは GitHub のみ | GitHub → Obsidian に自動同期 |
| Make.com: 1,000 ops/月 を12時間で使い切る | クレジット消費: **0** |

# PART 4：Obsidian Git 設定（約20分）

ナレッジが GitHub → Obsidian に自動で届くようにする。

---

## STEP 4-1：Git がインストールされているか確認

PowerShell を開いて：
```powershell
git --version
```

- `git version 2.x.x` → ✅ 次へ
- 「認識されていません」 → `https://git-scm.com/download/win` からインストール

---

## STEP 4-2：GitHub KCS-Vault リポジトリを作成

> 作成済みの場合はスキップ

1. `https://github.com` にログイン → 右上「+」→「New repository」
2. 設定：

   | 項目 | 値 |
   |---|---|
   | Repository name | `KCS-Vault` |
   | Visibility | **Private** |
   | Add a README file | ✅ |

3. 「Create repository」をクリック

4. リポジトリ内に以下のフォルダを作成（「Add file」→「Create new file」）：

   | ファイルパス | 目的 |
   |---|---|
   | `Knowledge/.gitkeep` | ナレッジメモ保存先 |
   | `Daily/.gitkeep` | 日次レポート保存先 |
   | `Projects/HAL/投稿ログ/.gitkeep` | HAL投稿案保存先 |
   | `Projects/HAL/実績ログ/.gitkeep` | HAL投稿実績保存先 |
   | `Projects/Affiliate/投稿ログ/.gitkeep` | すなくん投稿保存先 |

   各ファイルは空のままで「Commit changes」をクリック

---

## STEP 4-3：Personal Access Token を発行する

1. `https://github.com/settings/tokens` を開く
2. 「Generate new token」→「Generate new token (classic)」
3. 設定：

   | 項目 | 値 |
   |---|---|
   | Note | `KCS-Vault Obsidian` |
   | Expiration | **No expiration** |
   | Scope | **repo** にチェック |

4. 「Generate token」→ 表示されたトークン（`ghp_xxx...`）を**今すぐコピー**

5. **メモ帳に貼り付けて保存**（このページを閉じると二度と表示されない）

6. **GAS スプレッドシートの設定シート**にも追加：
   - `GITHUB_TOKEN` 行の値列に貼り付け
   - `GITHUB_OWNER` 行に GitHub ユーザー名を入力

---

## STEP 4-4：KCS-Vault をローカルにクローンする

PowerShell で実行（`TOKEN` と `ユーザー名` を置き換える）：

```powershell
cd C:\Users\kenny
mkdir ObsidianVaults
cd ObsidianVaults
git clone https://TOKEN@github.com/ユーザー名/KCS-Vault.git
```

例：
```powershell
git clone https://ghp_abc123@github.com/kenny1102/KCS-Vault.git
```

完了すると `C:\Users\kenny\ObsidianVaults\KCS-Vault` フォルダができる。

---

## STEP 4-5：Obsidian で Vault として開く

1. Obsidian を起動（未インストールなら `https://obsidian.md` からダウンロード）
2. **「Open folder as vault」** をクリック
3. `C:\Users\kenny\ObsidianVaults\KCS-Vault` を選択
4. 「**信頼する**」を選択

---

## STEP 4-6：Obsidian Git プラグインをインストール

1. 左下の歯車アイコン **「設定」** を開く
2. 左メニュー **「コミュニティプラグイン」** → **「コミュニティプラグインを有効化」**
3. **「閲覧」** をクリック
4. `Obsidian Git` を検索 → 作者 Vinzent03 のものを **「インストール」→「有効化」**

---

## STEP 4-7：Obsidian Git を設定する

設定 → 左メニュー最下部 **「Obsidian Git」** を開く：

| 設定項目 | 値 |
|---|---|
| Vault backup interval (minutes) | `0`（自動Pushなし） |
| **Auto pull interval (minutes)** | **`10`**（10分ごと自動Pull） |
| **Pull updates on startup** | **ON** |
| Push on backup | OFF |
| Username | GitHub ユーザー名 |
| Password / Token | STEP 4-3 のトークン（`ghp_xxx`） |

設定を閉じる。

---

## STEP 4-8：動作確認

1. Obsidian 左リボンの **「Source control」アイコン**（時計マーク）をクリック
2. 右パネルの **「Pull」** をクリック
3. エラーなし → ✅

**全体フローの最終確認：**

```
Discord: /knowledge memo:テスト投稿
        ↓ 約1分
Discord に「📚 ナレッジメモを保存しました」
        ↓
Obsidian で Pull
        ↓
Knowledge/メモ/memo_YYYYMMDD.md が現れる ✅
```
