# 🎀 メイク（Make.com）完全設定手順書
# 「HAL（ハル）アカウント・画像付きリアル日常投稿」フロー

## 📖 この手順書の目的
エックス（旧ツイッター）のハルアカウントにおいて、限界リアルペルソナに基づいた「人間味あふれる呟き」と、「まるで本人が撮ったかのようなリアルな写真（画像生成）」をセットにして全自動で投稿する仕組みを構築します。

---

## 🔧 事前準備チェックリスト

| 準備項目 | 内容 | 確認 |
|---------|------|------|
| グーグル・アップス・スクリプト（GAS）のウェブアプリURL | スプレッドシートからデプロイ済みのURL | [ ] |
| エックス（X）のエーピーアイキー（HAL用） | コンシューマーキー、アクセストークン等 | [ ] |
| オープンエーアイ（OpenAI）のキー | メイクで画像を生成するために使用（数百円程度の課金推奨） | [ ] |
| メイク（Make.com）アカウント | 無料プランでも動作可能 | [ ] |

---

## 📋 メイク（Make.com）シナリオの作成手順

### ステップ 1：新しいシナリオを作成
1. メイク（Make.com）にログインし、「Create a new scenario」をクリックします。
2. シナリオ名を「**KCS HAL 画像付き日常投稿フロー**」に設定します。

---

### ステップ 2：スケジュール（トリガー）の設定
**モジュール選択：** `Schedule - At regular intervals` (または一番最初の時計マーク)

1.  **実行間隔の設定：**
    毎日決まった時間にHALを呟かせるため、「毎日の指定時刻（Every day）」などに設定します。
    例：お昼の12:00、夜の21:00 など。

---

### ステップ 3：グーグル・アップス・スクリプト（GAS）で呟きと写真の指示書を生成
**モジュール選択：** `HTTP - Make a request`

HALのペルソナに基づいた「本日の呟き」と「どんな写真を生成すべきか」をジェミニに作らせます。

| 設定項目 | 値 |
|---------|---|
| URL | `（GASのウェブアプリURL）` |
| メソッド（Method） | `POST` |
| ボディ（Body Type） | `application/json` |
| ボディの内容 | 以下のジェイソン（JSON）を貼り付け |

```json
{
  "action": "generate_hal_post"
}
```

**レスポンスの確認：**
実行すると、`data.tweetText` に呟きの本文、`data.imagePrompt` に画像を作るための英語の指示（プロンプト）が入って返ってきます。

---

### ステップ 4：写真の自動生成（OpenAI / DALL-E 3）
**モジュール選択：** `OpenAI (ChatGPT, Whisper, DALL-E)` → 「Generate an Image」

GASが考えた指示（プロンプト）をもとに、リアルな写真を生成します。

| 設定項目 | 値 |
|---------|---|
| モデル（Model） | `dall-e-3` |
| プロンプト（Prompt） | `{{2.data.imagePrompt}}` （※ステップ3で取得した変数） |
| サイズ（Size） | `1024x1024` またはお好みのサイズ |
| 品質（Quality） | `Standard` または `HD` |

**レスポンスの確認：**
実行すると、生成された写真のウェブアドレス（URL）が `data.url` などの変数に入って返ってきます。

---

### ステップ 5：エックス（X）への画像付き投稿
**モジュール選択：** `HTTP - Make a request`（またはエックス公式モジュールの `Create a Tweet`）

生成した呟きのテキストと、写真のウェブアドレスを使って、HALのアカウントで投稿します。
※ここではエックス公式モジュール（`Create a Tweet`等）を使うのが最も簡単です。画像URLをメディアとして添付し、テキストに `{{2.data.tweetText}}` を入れます。

もしGASの既存機能（`postToX`）を経由させる場合は、以下のようになります。
| 設定項目 | 値 |
|---------|---|
| URL | `（GASのウェブアプリURL）` |
| メソッド（Method） | `POST` |
| ボディ（Body Type） | `application/json` |

```json
{
  "action": "post_hal_tweet_with_image",
  "tweetText": "{{2.data.tweetText}}",
  "imageUrl": "{{3.data.url}}",
  "account": "hal"
}
```
※上記のような追加のアクションは今回GAS側には実装していないため、**メイクのエックス公式モジュールを使って直接投稿する**ことを推奨します。

---

### ステップ 6：ディスコード（Discord）への完了通知
**モジュール選択：** `HTTP - Make a request`

| 設定項目 | 値 |
|---------|---|
| URL | `（ディスコードのウェブフックURL）` |
| メソッド（Method） | `POST` |
| ボディ（Body Type） | `application/json` |

```json
{
  "content": "🎀 **ハルの画像付き投稿が完了しました！**\n\n📝 本文:\n`{{2.data.tweetText}}`\n\n🖼️ 生成プロンプト:\n`{{2.data.imagePrompt}}`\n\n✨ 画像: {{3.data.url}}",
  "username": "ケーシーエス ハル 自動運用ボット"
}
```

## 🎯 設定完了後の動作確認
1.  メイクの画面左下「Run once（１回だけ実行）」ボタンでテスト実行します。
2.  ディスコードのチャンネルに通知と画像が届けば成功です。
3.  HALのエックスアカウントを確認し、リアルな写真とともに呟きが投稿されているかチェックしてください！
