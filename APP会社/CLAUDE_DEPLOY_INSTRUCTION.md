# 🤖 クロード・コード（Claude Code）専用：フロントエンド自動ビルド ＆ ファイアベース・デプロイ指示書

クロード・コード（Claude Code）へ：
以下の手順に従って、ウィンドウズ（Windows）環境におけるパワーシェル（PowerShell）のスクリプト実行制限を回避しながら、アバターフロントエンド（リアクト／React）のビルド（Build）およびファイアベース・ホスティング（Firebase Hosting）へのデプロイ（Deploy）を自律的に完了させてください。

---

## 🎯 今回のミッション
1.  プロジェクトルートディレクトリで、アセットが揃っていることを確認します。
2.  ウィンドウズのパワーシェル（PowerShell）における実行ポリシーによるエラー（`MODULE_NOT_FOUND` / `UnauthorizedAccess`）を回避しながらビルドを実行します。
3.  ファイアベース（Firebase）への本番デプロイを正常に完了させます。

---

## 🛠️ 実行ステップ（クロード・コードが自動実行する内容）

### ステップ １：プロジェクト環境の確認
以下のディレクトリが現在の作業ディレクトリであることを確認してください：
👉 `c:\Users\kenny\.gemini\antigravity\scratch\attendance_app\APP会社`

### ステップ ２：セキュリティ制限を回避したビルドの実行
ウィンドウズのパワーシェル制限を回避するため、通常の `npm` コマンドの代わりに **`.cmd` 拡張子付きのラッパー**を使用するか、またはシェル実行ポリシーを一時的に解除してビルドを行ってください。

以下のいずれかのコマンドをターミナルで実行してください：

**【推奨方法（ラッパー呼び出し）】**
```bash
npm.cmd run build
```

**【代替方法（実行ポリシーの一時バイパス後にビルド）】**
```powershell
# 制限の一時バイパス
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force

# 通常ビルドの実行
npm run build
```

ビルドが完了し、`dist/` フォルダの中に本番用ファイル群が正常に出力されたことを確認してください。

### ステップ ３：ファイアベース（Firebase）への本番デプロイ
ビルド完了後、同様のセキュリティ回避措置を適用して、本番ホスティング環境へアップロードします。

以下のいずれかのコマンドを実行してください：

**【推奨方法（ラッパー呼び出し）】**
```bash
npx.cmd firebase deploy
```

**【代替方法】**
```powershell
firebase deploy
```
