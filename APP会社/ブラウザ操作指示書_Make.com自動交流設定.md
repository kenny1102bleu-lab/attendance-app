# 🚀 メイク（Make.com）完全設定手順書
# 「すなアカウント自動交流・賢いリプライ」フロー

## 📖 この手順書の目的

エックス（旧ツイッター）上の一般ユーザーの呟きを検索し、人工知能（ジェミニ）を活用して「すな」のペルソナ（人格）で自動的に親切な返信（リプライ）を送る仕組みを構築します。
**売込みを控え、親切なアドバイスを優先する「賢い自動返信」**を採用しているため、スパム判定（シャドウバン）を防ぎつつ自然にファンを増やすことができます。

## 📋 メイク（Make.com）シナリオの作成手順

### ステップ 1：新しいシナリオを作成

1. メイク（Make.com）にログインし、「Create a new scenario」をクリックします。
2. シナリオ名を「**KCS すなくん 自動交流・リプライフロー**」に設定します。

---

### ステップ 2：トリガーの設定（エックスからの検索）

**モジュール選択：** `Twitter`（現在は `X` または `Twitter (legacy)` と表示される場合があります） → 「Search Tweets」

1.  **検索キーワード（Query）：**
    以下のいずれかのキーワードを設定します（例）。
    *   `おすすめのイヤホン`
    *   `キーボード 欲しい`
    *   `充電器 壊れた`
    *   `おすすめのパソコン`
    *   ※ `-RT` を後ろにつけるとリツイートを除外できます（例：`おすすめのイヤホン -RT`）
2.  **取得件数（Limit）：** `1`（１回の実行につき１件のみ取得するようにして安全性を確保します）

---

### ステップ 3：グーグル・アップス・スクリプト（GAS）で返信文を生成

**モジュール選択：** `HTTP - Make a request`

相手のツイート内容を人工知能（ジェミニ）に渡し、「すな」らしい返信テキストを作らせます。

| 設定項目 | 値 |
|---------|---|
| URL | `（GASのウェブアプリURL）` |
| メソッド（Method） | `POST` |
| ボディ（Body Type） | `application/json` |
| ボディの内容 | 以下のジェイソン（JSON）を貼り付け |

```json
{
  "action": "generate_auto_reply",
  "tweetText": "{{1.text}}"
}
```
※ `{{1.text}}` の部分は、ステップ2で取得したツイートのテキスト（Text）をマッピングしてください。

**レスポンスの確認：**
- `data.replyText` に、ジェミニが考えた親切な返信文が入って返ってきます。

---

### ステップ 4：エックス（X）へのリプライ送信

**モジュール選択：** `HTTP - Make a request`（またはエックス公式モジュールの `Create a Tweet`）

GASのエンドポイントを叩いて、すなくんアカウントでリプライ投稿を実行します。

| 設定項目 | 値 |
|---------|---|
| URL | `（GASのウェブアプリURL）` |
| メソッド（Method） | `POST` |
| ボディ（Body Type） | `application/json` |

```json
{
  "action": "post_affiliate_reply",
  "tweetId": "{{1.id}}",
  "replyText": "{{3.data.replyText}}",
  "account": "sunakun"
}
```
※ `{{1.id}}` はステップ2で検索した相手の投稿アイディーです。
※ `{{3.data.replyText}}` はステップ3で生成した返信テキストです。

---

### ステップ 5：ディスコード（Discord）への完了通知

**モジュール選択：** `HTTP - Make a request`

| 設定項目 | 値 |
|---------|---|
| URL | `（ディスコードのウェブフックURL）` |
| メソッド（Method） | `POST` |
| ボディ（Body Type） | `application/json` |

```json
{
  "content": "💬 **自動交流リプライを送信しました！**\n\n👤 相手の呟き: `{{1.text}}`\n\n✨ すなの返信: `{{3.data.replyText}}`",
  "username": "KCS 自動交流ボット"
}
```

---

### ステップ 6：スケジュールの設定（重要・シャドウバン対策）

シナリオの左下にある時計マーク（スケジュール設定）をクリックします。

*   **実行間隔（Run scenario）：** `180 minutes`（３時間おき）
*   **※注意※：** 最初は「１日に数回」からスタートしてください。急激に大量のリプライを送るとエックスの制限（シャドウバン）に引っかかる恐れがあります。
