## 新しいアーキテクチャ（完成後）

```
あなたが Discord でスラッシュコマンド入力
        ↓（Discord が直接 GAS を呼ぶ。ポーリングなし・クレジット消費なし）
GAS doPost（handleDiscordInteraction）
        ├─ /help /status /attendance /stock → 即時返答（1秒以内）
        └─ /ask /hal /sunakkun /daily /knowledge /approve /hp /ec
                → 「⏳ 処理中...」表示
                → 約1分後に結果が届く
                → 結果は各チャンネル（#hal-project 等）にも届く

GAS 定時トリガー（Make.com・n8n 不要）
        ├─ 毎朝8時 → morningBriefing() → #朝礼 に投稿
        └─ 毎晩20時 → generateDailyReport() → #daily-report に投稿
```

**Make.com の操作回数: 0  /  n8n: 不要**

## 手順

### STEP 1：GAS コードを更新してデプロイ（約5分）

#### 1-1. ローカルのコードをコピー

PC で以下のファイルを開く：
```
c:\Users\kenny\.gemini\antigravity\scratch\attendance_app\APP会社\GAS_KCS合同会社_Backend.gs
```
**全選択（Ctrl+A）→ コピー（Ctrl+C）**

#### 1-2. GAS エディターに貼り付け

1. Google スプレッドシート（KCS合同会社）を開く
2. メニュー → **拡張機能** → **Apps Script**
3. エディター内を全選択（Ctrl+A）→ 貼り付け（Ctrl+V）
4. 保存（Ctrl+S）

#### 1-3. 新バージョンでデプロイ

1. 右上「**デプロイ**」→「**デプロイを管理**」
2. 「**新しいデプロイ**」をクリック
3. 設定：
   - 種類: ウェブアプリ
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 「デプロイ」→ 権限承認

> ✅ **URL は変わらない** ので次の STEP でそのまま使用

### STEP 2：Discord Developer Portal で Interactions Endpoint を設定（約5分）

Discord のスラッシュコマンドが GAS を直接呼ぶための設定。

1. ブラウザで以下を開く：
   ```
   https://discord.com/developers/applications/1494714160829693992/information
   ```

2. 左メニュー「**General Information**」を選択

3. 下にスクロールして「**Interactions Endpoint URL**」欄を探す

4. 以下の URL を入力：
   ```
   https://script.google.com/macros/s/AKfycbxmVS3EyDiT8KtX4r10SIE8eDu3ri_7aRbYXR4kFpEqSKuQnDsJLlTO1HV6p7RW1mTF/exec
   ```

5. 「**Save Changes**」をクリック

> ✅ 「Interactions Endpoint URL is valid」と表示されれば成功  
> ❌ エラーが出た場合 → STEP 1 のデプロイが完了していない（再確認）

---

### STEP 3：GAS でスラッシュコマンドを Discord に登録（約2分）

GAS エディターに戻って、以下の関数を手動実行する。

1. GAS エディター上部の関数名プルダウンを開く
2. **`registerDiscordSlashCommands`** を選択
3. **▶ 実行** をクリック
4. 「✅ Slash Commands 14個を登録しました！」のアラートが出れば成功

> この操作は**1回だけ**。以降は自動で使えるようになる。

---

### STEP 4：GAS で定時トリガーを設定（約2分）

朝礼と日次レポートの自動実行を GAS 内で完結させる。**n8n は不要。**

1. GAS エディターの関数名プルダウンで **`setupAllTriggers`** を選択
2. **▶ 実行** をクリック
3. 「✅ トリガーを設定しました（朝8時: morningBriefing, 夜8時: generateDailyReport）」が出れば成功

> これで n8n の 01_朝礼フロー と 06_日次レポート が GAS に置き換わる。

---

### STEP 5：Make.com を無効化（約2分）

Make.com のポーリングが残っていると「返答が2回来る」状態になるため必ず無効化。

1. Make.com にログイン
2. **Scenarios** を開く
3. `KCS Discord → GAS 中継` → トグルを **OFF**
4. `KCS #knowledge 画像解析` → トグルを **OFF**

> シナリオは削除しなくてよい。OFF にするだけでOK。

## よくあるエラーと対処

| エラー | 原因 | 対処 |
|---|---|---|
| Discord: 「Interaction failed」 | GAS が 3秒以内に応答できなかった | STEP 2 のデプロイを確認 |
| 「Interactions Endpoint URL is invalid」 | GAS URL が間違い / デプロイ未完了 | STEP 1 を再確認してから URL を再入力 |
| スラッシュコマンドが Discord に表示されない | 登録が反映されるまで最大1時間かかる | しばらく待ってから Discord を再起動 |
| AI コマンドの結果が届かない | followup token の有効期限切れ（15分） | もう一度コマンドを実行 |
| 返答が2回来る | Make.com が残っている | STEP 5 で Make.com を OFF に |
| `/attendance` でエラー | `ATTENDANCE_GAS_URL` 未設定 | GAS 設定シートに勤怠 GAS の URL を入力 |
